# Bengali Voice Typing (বাংলা ভয়েস টাইপিং)
Native Android Kotlin & Jetpack Compose application using Android's built-in SpeechRecognizer.

## Setup Instructions:
1. Open Android Studio -> Open Project -> Select this extracted folder.
2. Allow Gradle sync to download dependencies.
3. Connect an Android phone or launch an emulator.
4. Run the project (Shift + F10).
